### 架构要点（本发布）

- **子代理并行优先（V10.139）**：信息分类原则——决策/实现/验证信息进主上下文；
  批量调查中间信息由子代理隔离消化，只回传精炼结论（file:line 锚点）；提示词
  三处强化 + 宿主信号（单轮纯调查 ≥8 次注入改用 explore 引导，per-turn 上限 3）
- **技能触发修复（V10.140）**：autoTriggerRules 关键词扩展（"修复/bug/故障/
  不工作/失败"等常见措辞）；Solo 提示词要求 inline 技能任务匹配时主动 run_skill
- **验证分级（V10.141）**：Go 改动→build+受影响包测试；前端→tsc/前端测试；
  文档/配置→内容核对；跨模块/重构→全量套件。verify_gate nudge 与提示词清单同步
- **构建脚本（V10.138）**：自动探测 tools\go\tools\node\Wails CLI 补 PATH
  （注意 bat 注释必须纯 ASCII）
